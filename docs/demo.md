# Reproduce the demo

Follow the prerequisites and installation steps in the [README](../README.md), then run:

```sh
python examples/demo.py
```

The GIF and MP4 replay output from this executable demo. Presentation timing and layout are edited for readability. The recorded observations are in [demo-evidence.json](../assets/demo-evidence.json). Temporary machine paths are omitted.

The input is a generated fixture. Size, speed and quality depend on the input and FFmpeg build; the recorded scores are not a promise for your videos. VMAF requires libvmaf.
